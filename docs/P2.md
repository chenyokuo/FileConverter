# P2 — 進階工具箱

在 P0/P1 的既有介面上加入後端宣告式工具目錄與獨立工具 Modal，未建立 Release／Installer／Portable。

PDF：頁面排序、裁切、無損／有損壓縮、添加／移除可獨立辨識浮水印、頁碼、AES-256 密碼保護及具授權密碼的解密、本機 OCR 與可搜尋 PDF；原有合併、分割、旋轉、圖片輸出仍保留。

圖片：批次縮放／裁切／旋轉、壓縮與目標大小搜尋、浮水印、清除 EXIF/GPS、實際中繼資料報告、OpenCV 非 AI 局部修補。區域可在預覽拖曳，提供前後圖片、大小變化、還原及取消；未達目標大小會明確提示。DOCX/PPTX 只移除獨立標示的 Shape，保留一般內文。

影音：精準或關鍵影格裁切、相容串流直接合併、不相容來源正規化、Remux、GIF、指定影格、文字字幕抽取／封裝、兩階段 EBU R128 音量標準化、固定區域 delogo。原有 bitrate/CRF/FPS/解析度與 GPU/CPU 流程保留。融合像素修補不承諾還原原始內容。

壓縮／檔案：ZIP/7Z/TAR/GZ 建立與解壓、RAR 僅解壓、內容清單、ZIP/7Z/TAR 轉換、另存批次命名、SHA-256 比對與重複檔分組。解壓前拒絕路徑穿越、Windows 特殊路徑、重複大小寫路徑、連結和異常資源展開量；空來源不交給 CLI，避免意外處理目前工作目錄。原始檔不刪除或覆寫。

新增工具共用 Windows 隔離工作程序、並行佇列、取消、歷史與輸出衝突處理。密碼僅存在工作記憶體和 worker stdin，不寫入歷史；重試需重新輸入。處理預覽不留在一般歷史，取消後終止任務並清理私有預覽目錄。

簡測：`tests/test_p2.py` 9 個群組通過，驗證實際 PDF 頁面／文字、OCR 辨識字串、解密、密碼歷史隔離、像素與尺寸、EXIF 清除、目標大小提示、Office Shape 與原文保留、各壓縮格式解壓內容、惡意路徑與連結拒絕、影片長度／影格／字幕／音訊、Remux、預覽與資料夾發布。RAR 另以 libarchive 官方開源 RAR5 stored 素材實際解壓 `helloworld.txt`，素材 SHA-256 `35d75e315d164d2e329afc28f7d844f013271b4fcffd4ddd78efcdd114a383a7`，只存於忽略的測試目錄。安全修正後只重跑受影響的 PDF／壓縮案例。TypeScript 與 Python 語法通過。

介面與完整格式變體回歸統一於 P5；此階段不宣稱已完成正式 Windows 安裝驗收。
