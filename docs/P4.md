# P4 — Windows 整合與自動化

新增可新增、命名、編輯、刪除、保存與套用的轉檔預設和多步驟工作流程。步驟共用 Registry／工具參數驗證，可調整順序、預覽格式路徑及批次執行。逐步重新檢查實際檔案內容；遇錯可中止或略過，記錄實際失敗步驟。密碼工具和多來源合併不納入無人值守流程。

資料夾監看需明確選擇來源／輸出並手動開始，只掃描直接子檔案，不跟隨連結。大小／修改時間穩定 1.5 秒且 Windows 寫入控制代碼釋放後才入列；以內容雜湊防止同檔無變更的再次觸發。拒絕互相包含的來源／輸出。提供暫停、恢復、停止及本次執行紀錄；重開程式須再次啟用，不默默讀取資料夾。

檔案預覽支援圖片、PDF 換頁、Office 本機 PDF 渲染、影片影格、音訊資訊和本機轉碼最多 15 秒試播。歷史可並排／滑動比較前後結果及檔案大小、頁數、尺寸、編碼資訊。暫存使用私有目錄，Windows 清理支援長路徑；外部 Runtime 結束時等待其隔離 Job 中的子程序退出。

選用的右鍵整合只建立目前使用者 `Software\Classes\*\shell\FileConverter` 和 `SystemFileAssociations\.ext\shell\FileConverterTo...` 專屬項目，依實際矩陣提供 PDF/JPG/MP3。禁用只刪除具本程式 Owner 標記的項目。沒有改預設應用程式、OpenWith、ProgID 或 DefaultIcon。官方 Single Instance 插件 2.5.5 轉送右鍵檔案到同一視窗；只匯入並選擇目標，不自動執行轉換。解除安裝清理由 P5 Installer hook 整合。

`tests/test_p4.py` 六群組：圖片尺寸／EXIF／多檔命名與衝突、預設 CRUD／重啟保存、PDF OCR→DOCX 內文、MOV→H.265 實際編碼、失敗中止／略過、非法矩陣拒絕、監看寫入鎖／去重／暫停／停止／重開停用、PDF/Office/音訊/影片實際預覽，以及右鍵路徑邊界。五群組一次通過，預覽群組修正長路徑後重測通過。TypeScript、Python、Rust 增量檢查通過。實際桌面單一執行個體、右鍵啟停與 Installer 解除安裝驗證留在 P5 統一驗收；沒有產生中途正式封裝。
