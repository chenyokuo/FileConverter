# P1 — 轉換引擎與 Runtime

從 P0 526dc52 延伸原有 Adapter／佇列。未進行任何應用 Release、Installer 或 Portable 封裝。

已實作：HEIC／AVIF／GIF 及動畫 GIF/WebP；PDF → DOCX／TXT；DOC↔DOCX、DOCX↔ODT、XLS↔XLSX、XLSX↔ODS、CSV↔XLSX、PPT↔PPTX、PPTX↔ODP 與 Office→PDF；MD↔HTML、MD→DOCX；SVG／EPS／PDF 向量管線；WMV；Calibre EPUB／MOBI／AZW3／FB2。

Runtime 僅由 `vendor` 解決，不退回系統安裝的 Office／Pandoc／Calibre。LibreOffice、Calibre 以 MSI 管理映像解壓，沒有安裝產品或修改檔案關聯。`engine-lock.json` 固定 Runtime 版本、來源與 SHA-256；P5 才將必要檔案整合到正式套件。文件引擎採可內嵌且已實測的 LibreOffice headless，不新增需要使用者 Office 安裝的依賴。Python 鎖檔不包含 AI／LLM 套件。

硬體模式為自動／NVIDIA／AMD／Intel／CPU，H.264 與 HEVC 分開實際編碼探測。能力探測在背景進行，不阻塞檔案匯入；影片任務共用已探測結果。GPU 編碼失敗會清除中間檔並以 CPU 重試，回報實際編碼器、FPS、速度與備援原因。NVDEC 在 NVIDIA 任務使用實際輸入嘗試，不可用時一併回退。

簡測結果：圖片與動畫、PDF→DOCX 內容、TXT、Markdown／HTML／DOCX、SVG／EPS、實際影音輸出通過；Office 內容往返與電子書六組往返內容驗證通過。測試曾暴露 Office 私有設定目錄和唯讀 lock 檔清理問題，已以獨立 Windows Job Object 與受限 staging 清理修正，另外重測 Office 輸出及清理。TypeScript、Rust `cargo check`、Python 語法檢查通過。實測本機 AMD H.264 可用，NVIDIA／Intel 不可用；其他硬體不宣稱已實機認證。

完整格式配對、凍結 Runtime、乾淨 Windows、速度／畫質比較及完整回歸留到 P5；Registry 保留未實測配對標記，PDF→DOCX 明示版面失真限制。沒有宣稱 P5 的免額外安裝驗收已完成。
