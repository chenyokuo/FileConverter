# P5 候選交付驗證 — 1.0.0-rc.1

驗證日期：2026-11-16～17。**P1–P4 實作完成；P5 在目前主機的候選驗證完成後，仍待乾淨 Windows／實體環境及相應來源散布閘門，不宣稱正式全部驗收通過。**

## 已完成

- 305 個宣告直接方向實際轉換並解碼／檢查內容，矩陣見 [FORMATS](FORMATS.md)。
- 完整來源 55 項回歸；凍結版核心 23 項及 P2–P4 20 項。原本 missing-LO 跳過項後續用空 Runtime 實測來源／frozen 均通過；新增影片預覽、繁中／Unicode 模型目錄等案例亦通過。
- 實際 Portable 的 23 組原生 GUI／IPC、250 個長中文檔名、硬體／容器選項、Windows 圖示、單一視窗轉送及右鍵啟停通過。沒有使用 Computer Use；採真實 WebView2/CDP、CLI 與原生 Windows API。
- 原始碼與最後 Sidecar 的 OCR、流程、媒體修正只重測相關案例。最後 Portable／Installer 均實際產生 JPG、含原文的 Office PDF 和可搜尋的繁中 OCR PDF；不是匯入套件或產生空檔驗收。
- 真正執行 Installer 安裝與解除安裝。桌面／開始功能表指向本次 `FileConverter.exe`；解除安裝移除 EXE、捷徑、46 個具本程式 Owner 的 shell verbs。設定、歷史及自動化 SQLite 各表語意雜湊前後相同，保留使用者資料。
- app-local 固定 WebView2 157.0.4341.60 的 Microsoft 簽章 Valid；運行時回報同版。以只有 Windows 系統目錄的 PATH 進行 frozen 代表功能及 Portable／Installer 測試，未從 PATH 依賴 Python、Node、Office 或 FFmpeg 安裝。
- 本機 CPU／AMD 輸出、FPS／SSIM、AMD HEVC 不支援時 libx265 備援、1 GiB WAV 串流處理已驗證，數據及限制見 [VALIDATION](VALIDATION.md)。

## 實際錯誤與修正

首次完整 Release 成功後，NSIS Solid 壓縮遇到大型資料映射限制；使用固定提交的官方模板，改非 Solid zlib 並停用資料去重搜尋。只針對實際建置／驗收錯誤做 app crate 增量更新或 NSIS 重新封裝，沒有在 P1–P4 產生 Installer。

另修復 Runtime 授權檔唯讀屬性阻止增量覆寫、LibreOffice 自測鎖檔與長路徑清理、安裝版 `\\?\` 路徑被 C OCR 引擎拒絕、Unicode 模型目錄、繁中優先順序、編輯參數後殘留舊預覽、舊 NVENC 選項繞過能力檢查及品質預設未傳入部分編碼器。所有修正都有相關實際輸出或 GUI 驗證。未修改系統檔案關聯、預設應用程式或全系統圖示快取。
