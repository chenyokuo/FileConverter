後端 `engine/registry.py` 為唯一相容矩陣，GUI 與 worker 共用。多步驟需在工作流程中明確建立，沒有暗中執行任意中介路徑。

PDF→DOCX／OCR 需校對；圖片有損格式與重新編碼可能改變品質；GIF/WebP 以外輸出使用第一畫格。詳見 README 與工具內提示。
