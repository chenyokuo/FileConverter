# 處理工具

所有下列工具使用既有隔離工作佇列、取消、衝突另存與歷史紀錄。原有直接格式轉換與 PDF 合併／分割／旋轉另見格式矩陣。

| 分類 | 工具 | 實際邊界 |
|---|---|---|
| PDF | PDF 頁面排序 | 輸入明確頁碼順序，例如 3,1,2；也可重複或擷取頁面 |
| PDF | PDF 裁切 | 在頁面預覽拖曳區域，套用至所有頁面；原檔保持不變 |
| PDF | PDF 壓縮 | 無損重整或有損影像壓縮；不保證檔案一定變小 |
| PDF | PDF 添加浮水印 | 新增獨立標記物件，可由移除工具還原 |
| PDF | PDF 移除獨立浮水印 | 只移除本程式標記、Artifact Watermark 或可獨立辨識的圖層；不刪除融合像素 |
| PDF | PDF 添加頁碼 | 在每頁頁尾添加數字 |
| PDF | PDF 密碼保護 | AES-256 加密；密碼不寫入歷史紀錄 |
| PDF | PDF 授權解密 | 僅使用已知且具修改權限的密碼，不繞過存取限制 |
| PDF | PDF OCR／可搜尋 PDF | 本機 Tesseract OCR；掃描辨識可能有誤，請校對 |
| 圖片 | 批次縮放 | 任一尺寸為 0 時維持比例 |
| 圖片 | 批次裁切 | 預覽拖曳區域，依比例套用到每張圖片 |
| 圖片 | 批次旋轉 | 另存處理後圖片，不修改原檔 |
| 圖片 | 圖片壓縮／目標大小 | 以合理最低品質搜尋目標；無法達成時明確回報。PNG 使用無損最佳化 |
| 圖片 | 圖片添加浮水印 | 在手動選取區域加入文字 |
| 圖片 | 清除 EXIF／GPS | 重新輸出並清除 EXIF、GPS 與其他中繼資料 |
| 圖片 | 檢視中繼資料 | 讀取尺寸、EXIF／GPS、格式與動畫資訊，另存 JSON 報告 |
| 去浮水印／物件修復 | 圖片局部修補 | OpenCV 非 AI 修補；無法完美恢復被遮住的原始像素 |
| 去浮水印／物件修復 | DOCX／PPTX 移除獨立浮水印 | 僅移除明確標示的浮水印 Shape；不刪除一般內文 |
| 影片 | 影片裁切 | 精準模式重新編碼；快速模式只做關鍵影格裁切 |
| 影片 | 影片合併 | 相容串流直接合併；不相容時統一尺寸及編碼，缺音軌片段補靜音 |
| 影片 | 影片 Remux | 直接重新封裝，不重新編碼；來源串流必須與容器相容 |
| 影片 | 影片轉 GIF | 輸出調色盤最佳化動畫 GIF |
| 影片 | 擷取指定影格 | 依時間另存 PNG |
| 影片 | 字幕抽取 | 僅支援文字字幕；序號依影片預覽的字幕列表 |
| 影片 | 字幕封裝 | 先加入影片，再加入 SRT／ASS／VTT；不燒入畫面 |
| 去浮水印／物件修復 | 影片固定區域修補 | FFmpeg delogo，非 AI；區域需保留邊界，不能完美恢復原始像素。預覽處理前 10 秒 |
| 音訊 | 音訊裁切 | 依時間精準另存音訊 |
| 音訊 | 音量標準化 | EBU R128 兩階段量測及處理 |
| 壓縮 | 建立壓縮檔 | ZIP／7Z／TAR；GZ 只接受單檔。支援加入資料夾 |
| 壓縮 | 安全解壓縮 | ZIP／7Z／RAR／TAR／GZ；檢查路徑、連結與展開資源，另存資料夾 |
| 壓縮 | 壓縮格式轉換 | 先安全解壓，再建立 ZIP／7Z／TAR；不建立 RAR |
| 壓縮 | 壓縮檔內容預覽 | 不解壓，另存檔名、大小與路徑檢查 JSON |
| 檔案 | 另存批次重新命名 | 複製至輸出資料夾；保留原檔。可用 {stem}、{index}、{ext} |
| 檔案 | SHA-256 驗證 | 逐位元讀取檔案，可輸入一個預期雜湊比對 |
| 檔案 | 重複檔案偵測 | 依大小與 SHA-256 分組，不刪除任何檔案 |

工作流程只接受單一來源且不需密碼的處理步驟；每個階段重新檢查內容。需要多來源合併、密碼或特定字幕軌選擇時，使用互動工具介面。

素材與來源檔案保持不變；「另存批次重新命名」只複製到輸出，沒有偷偷改動原檔。壓縮檔拒絕路徑穿越／連結；OCR、像素修補、有損編碼皆需自行確認輸出。
