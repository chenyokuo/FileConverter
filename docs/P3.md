# P3 — 網址下載

加入使用內建 yt-dlp、Deno 與本機 EJS 的選用下載頁面。只有主動解析／下載網址才連線，本機轉檔不依賴網路。來源解析列出實際提供的格式、字幕語言與播放清單，逐項勾選後加入共用受限工作佇列；支援 MP3/M4A/FLAC/WAV 音訊輸出及下載後 MP4/MKV/WebM 轉檔。

進度使用 yt-dlp 真實位元組、速度與 ETA；後處理另顯示階段。取消會終止 worker 和子程序，保留私有 `.part` 快取供重試續傳；完成後清理。密碼、瀏覽器 Cookie、DRM 繞過、遠端執行元件皆未加入。下載結果只發布影音和字幕，不執行下載檔。

`tests/test_p3.py` 五組測試全部通過：自行產生並在本機 HTTP 測試伺服器提供合法素材，驗證 720p/1080p HLS 實際格式、指定畫質與轉檔、播放清單只選一項、字幕內容、四種音訊實際編碼、取消、HTTP Range 續傳，以及同時進行圖片轉檔。外部網站支援會隨站台改動，未把測試解讀為所有平台永久可用。TypeScript／Python 語法與 Rust 增量檢查通過；沒有建立 Release、Installer 或 Portable。
